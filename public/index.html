InputGuard

AI Privacy Bodyguard for everything you type — powered by Firebase AI Logic.

🔒 On-device

Keystrokes never leave your device

Input sensitivity is classified locally by Gemini Nano 4 via Firebase AI Logic. Nothing you type is uploaded to the cloud.

☁️ Cloud

Site reputation needs the cloud

Only the website domain (never your text) goes to Gemini in the cloud to score how trustworthy the site is.

🚨 Real-time

Warnings as you type

Fields light up red the moment sensitive data (PII, passwords, financial info) heads to an untrusted site.

Why the hybrid architecture wins

Privacy-critical analysis must stay on-device. Deep site reputation needs the cloud. InputGuard routes each job to the right model through Firebase AI Logic — a genuine hybrid AI story, not a gimmick.
