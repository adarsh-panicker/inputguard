Interactive Judging & Testing Guide

Follow these steps to observe the Firebase AI Logic hybrid inference in action:

  • 1

    Type expected safe data

    Click "Sample" on Name or Email. Because these are standard non-critical inputs, the field stays neutral with no alarm.

  • 2

    Type sensitive PII (SSN or Card)

    Click "Sample SSN" or type 123-45-6789. The field immediately lights up with a red danger outline and an inline 🔒 on-device badge appears!

  • 3

    Verify Zero-Egress Privacy

    Open Chrome DevTools → Network tab. Notice that zero keystroke data was transmitted to any server. Gemini Nano 4 classified the sensitive data completely locally.

  • 4

    Open the Side Panel & Dashboard

    Click the extension icon or side panel. Anonymized security audit events (Category, Timestamp, Confidence, Domain) are logged in real time to Cloud Firestore via Firebase Auth.
